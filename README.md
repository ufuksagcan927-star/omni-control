# Omni Control

Omni Control is a powerful remote management application that allows you to seamlessly control and monitor your Windows PC directly from your mobile phone. 

## Features

*   **Hardware Monitoring:** Real-time tracking of CPU and RAM usage, system temperature, and fan speeds.
*   **System Controls:** Easily adjust PC volume and screen brightness.
*   **Remote Input & Display:** View your PC screen live on your phone and control the mouse using the virtual touchpad.
*   **Media Controls:** Manage your media players remotely (play, pause, skip, etc.).

## Platform Support
*   **PC:** Exclusively for Windows Operating Systems.
*   **Mobile:** Android (APK provided).
